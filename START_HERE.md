# Запуск Сова

Для агента: прочитай `skill/sova/SKILL.md`, затем при необходимости
`skill/sova/references/workflow.md`. Выполни исследовательскую задачу,
которую пользователь добавил в сообщении. Если задания пока нет, кратко сообщи,
что пакет готов, и попроси само задание или файл с ним.

Используй штатные модели, поиск, браузер, файловые инструменты и доступные
субагенты текущего приложения. Не настраивай сторонние API и не запрашивай ключи.
Сохраняй исследование в `research/<имя-проекта>/` и продолжай до результата в
рамках доступных инструментов. При продолжении существующей работы сначала
прочитай её state.json и текущие материалы.
