# Архитектура без отдельных API

Уточнённая цель: Сова используется внутри Codex, Claude Code и
Antigravity, быстро устанавливается в проект и не требует внешних API-ключей.

Исполнение обеспечивает текущий агент приложения. Общий SKILL.md описывает роли,
доказательность, автономный цикл и ограничения; references/workflow.md задаёт
структуру файлов и контракт делегирования. Субагенты запускаются только штатным
инструментом хоста, при его наличии и разрешении. Без них роли выполняются
последовательно с честным обозначением самопроверки.

Локальный Python 3.10+ помощник без зависимостей создаёт папку исследования,
проверяет структуру данных, сохраняет переходы этапов и собирает Markdown с
библиографией. Он не вызывает модели и не выполняет сетевых запросов.
Сохранение атомарное; параллельные изменения состояния блокируются lock-файлом.
Исследователи пишут раздельные заметки; общие файлы изменяет координатор.

Установка копирует skill в .agents/skills для Codex и Antigravity и .claude/skills
для Claude Code. Конфликтующие файлы не перезаписываются. Глобальные настройки и
корневые правила проекта не изменяются. START_HERE.md даёт явный путь запуска,
если автообнаружение skills недоступно в конкретной версии приложения.

Исследование требует доступных источников. Структурный валидатор не проверяет
истинность содержания; за содержательную проверку отвечает критик. После трёх
неудачных исправлений сохраняется needs_review, а не ложная готовность.

План проверки: локальная установка и её повторение; сохранность чужих файлов;
переходы этапов; отклонение неизвестных цитат; отказ после лимита доработок;
реальный цикл создания final/report.md; проверка поведения skill отдельным агентом.
